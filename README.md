## Что это

YT Lite — неофициальный клиент YouTube с входом в аккаунт. Главная идея — минимальный расход батареи и трафика: в фоне играет только звук, видео не загружается, модем не работает без нужды.

## Возможности

**Лента и поиск**
- Главная (рекомендации), подписки, история — с переключением свайпом и сохранением позиции
- Поиск с подсказками и историей, каналы в результатах
- Страницы каналов, подписка и отписка
- Несколько аккаунтов с переключением

**Плеер**
- В фоне только звук; кнопка «Только звук» и при открытом экране
- Двойной тап — перемотка на 5 с (каждый следующий тап — ещё 5 с)
- Свайп вниз — свернуть в мини-плеер; в полноэкранном режиме свайпы яркости и громкости
- Главы на полосе прогресса, кликабельные таймкоды
- Продолжение с места остановки
- Пропуск рекламных вставок авторов через [SponsorBlock](https://sponsor.ajay.app)
- Отдельное качество по умолчанию для Wi-Fi и мобильной сети

**Под видео**
- Описание, лайк/дизлайк, комментарии с ответами, написание комментариев
- Рекомендации

**Прочее**
- Открывает ссылки YouTube из других приложений и меню «Поделиться»
- Сам проверяет обновления

## Как экономится батарея

| Что делает | Зачем |
|---|---|
| Экран плеера закрыт → видеодорожка отключается | видео не скачивается и не декодируется |
| Звук AAC + audio offload | в фоне звук декодирует аудиопроцессор, основной процессор спит |
| Буфер до 10 минут | модем скачивает большой кусок и надолго засыпает |
| Нет фоновых сервисов и синхронизаций | приложение не работает, когда вы им не пользуетесь |

## Установка

1. Скачайте APK из [последнего релиза](https://github.com/Wydexyt/Ytlite/releases/latest) и установите (разрешите установку из этого источника).
2. **Xiaomi / HyperOS:** настройки приложения → «Контроль активности» → «Нет ограничений», иначе система будет прерывать фон.
3. **Чтобы ссылки YouTube открывались в YT Lite:** настройки приложения → «Открывать по умолчанию» → включить «Открывать поддерживаемые ссылки» и отметить адреса. Если установлен официальный YouTube — у него это же выключить.

Обновления ставятся поверх, вход в аккаунт сохраняется.

## Сборка

Каждый пуш в `main` собирается в GitHub Actions и публикуется в релизы. Локально:

```bash
./gradlew assembleRelease
```

Для подписи постоянным ключом нужны секреты репозитория `KEYSTORE_B64` и `KEYSTORE_PASSWORD`; без них локальная сборка подписывается debug-ключом.

## Если что-то сломалось

YouTube регулярно меняет защиту видеопотоков. Если видео перестали открываться — чаще всего помогает обновить [NewPipeExtractor](https://github.com/TeamNewPipe/NewPipeExtractor/releases) в `app/build.gradle.kts`. Сообщить о проблеме — через [Issues](https://github.com/Wydexyt/Ytlite/issues).

План развития — в [docs/ROADMAP.md](docs/ROADMAP.md), история изменений — в [CHANGELOG.md](CHANGELOG.md).

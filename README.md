# YT Lite

Лёгкий клиент YouTube для Android: вход в аккаунт, главная (рекомендации), подписки, история, поиск. Видео смотрится как обычно, в фоне играет только звук.

## Сборка
1. Распакуйте архив и откройте папку в Android Studio (File → Open).
2. Дождитесь Gradle Sync. Если Studio предложит обновить AGP/Kotlin/библиотеки, соглашайтесь.
3. Build → Build App Bundle(s)/APK(s) → Build APK(s). Лучше собрать release:
   в терминале Studio `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
   (он меньше и быстрее debug-версии, подписан debug-ключом для установки себе).
4. Установите APK на телефон.

## Что сделано ради батареи
- Ушли с экрана плеера → видеодорожка отключается, видеопоток не качается и не декодируется.
- Звук AAC + audio offload: в фоне декодирует аудио-DSP, процессор спит.
- Буфер до 10 минут: модем скачивает большой кусок и засыпает, а не тянет данные постоянно.
- Никаких фоновых сервисов, синхронизаций и уведомлений, кроме плеера во время воспроизведения.

## Xiaomi / HyperOS
Настройки приложения YT Lite → Контроль активности → «Нет ограничений», иначе система может прерывать фон.

## Если что-то сломалось
- Видео не открываются → обновите версию `NewPipeExtractor` в `app/build.gradle.kts`
  (https://github.com/TeamNewPipe/NewPipeExtractor/releases). YouTube регулярно меняет защиту потоков.
- Ленты пустые / «Войдите в аккаунт», хотя вход был → выйдите и войдите заново (cookie истекли).
- Google пишет «браузер небезопасен» при входе → попробуйте ещё раз позже или другой способ входа (пароль вместо passkey).

Качество видео ограничено 1080p: `Streams.maxHeight`.

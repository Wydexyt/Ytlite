# Выпуск версий

| Ветка | Что выходит | Пример |
|---|---|---|
| `dev` | только проверка сборки, без релиза | 0.3.0-dev25 |
| `beta` | предрелиз (тестовая версия) + файл отката | 0.3.0-beta.1, 0.3.0-beta.2… |
| `main` | стабильный релиз; повторный пуш той же версии — хотфикс | 0.3.0, 0.3.0.1… |

- Версия берётся из `version.properties`. Для новой беты: поднять версию (например `0.3.0`) и запушить в `beta`.
- К каждой бете прикладывается `YTLite-<стабильная>-rollback.apk`: последняя стабильная версия с внутренним номером выше беты — ставится поверх без удаления, вход и настройки сохраняются.
- Внутренний номер (versionCode) = номер запуска × 2 + 100; у файла отката +1. Поэтому новая сборка всегда ставится поверх предыдущей.
- В приложении: меню аккаунта → «Обновления: стабильные / тестовые»; на бете есть пункт «Вернуться на стабильную версию».

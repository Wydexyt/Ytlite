# YT Lite TV — отдельное приложение для Android TV

Отдельный APK, чтобы мобильный клиент не тянул ТВ-функции, а ТВ-клиент — мобильные.

## Устройство репозитория
- `core` — общий модуль-библиотека: InnerTube (ленты, поиск, комментарии, подписки), Streams/AccountStreams (потоки, 18+),
  Auth (аккаунты), PlaybackService (плеер, буфер, SponsorBlock, статистика), Prefs, ErrorLog, Updates.
  Исправления под изменения YouTube делаются один раз — для обоих приложений.
- `app` — мобильный клиент (как сейчас).
- `tv` — ТВ-клиент, свой `applicationId` (`by.hradovich.ytlite.tv`), свой интерфейс.
- Сборка выпускает два APK в одном релизе: `YTLite-<версия>.apk` и `YTLiteTV-<версия>.apk`; проверка обновлений в каждом берёт свой файл.

## Что нужно в ТВ-клиенте
- [ ] Видимость в лаунчере ТВ: категория LEANBACK_LAUNCHER, баннер 320×180, `uses-feature touchscreen required=false`
- [ ] Интерфейс для пульта: строки/сетка карточек, понятный фокус (подсветка, увеличение), навигация стрелками
- [ ] Разделы: Главная, Подписки, История, Поиск (экранная клавиатура + голосовой ввод), каналы
- [ ] Плеер на весь экран с управлением пультом: OK — пауза, ←/→ — перемотка, ↑/↓ — панель с качеством, скоростью, описанием
- [ ] Вход в аккаунт по коду с телефона (или перенос аккаунта из мобильного YT Lite через QR), без набора пароля пультом
- [ ] Рекомендации и «следующее видео» после окончания (на ТВ это ожидаемо)
- [ ] Без мобильного: мини-плеера, свайпов, жестов, щипка, «только звук», фонового режима

## Не нужно
- Комментарии с вводом текста (только чтение — по желанию)
- Мобильные настройки качества (Wi-Fi/моб. сеть) — на ТВ одно качество

# План развития

## В планах
- [ ] Экран «Статистика» (пункт в меню аккаунта), за неделю / месяц / всё время:
  - общее время просмотра и график по дням
  - время в фоне / «Только звук»
  - сэкономленный трафик (оценка: время без видео × битрейт видео при текущем качестве + пропущенное SponsorBlock)
  - SponsorBlock: сколько вставок пропущено и сколько времени сэкономлено
  - число просмотренных видео, самые смотримые каналы (топ-5)
  - Счётчики без опроса и таймеров: считаются только по событиям плеера (старт/пауза/смена видео), запись раз в событие — на батарею не влияют
- [ ] Анимация загрузки лент как в YouTube: вместо крутящегося кружка — серые карточки-заглушки (превью + аватар + строки) с переливающимся бликом, пока грузятся фиды; при запуске — заставка с иконкой (SplashScreen) до появления первых карточек
- [ ] Иконка приложения слева от надписи «YT Lite» в шапке
- [ ] Загружать все три ленты (Главная, Подписки, История) при запуске, а не при первом открытии вкладки: сначала Главная, сразу после неё — остальные (только списки; превью грузятся по мере показа)
- [ ] Анимации как в официальном приложении. Плеер перенести из отдельного экрана в выезжающую панель поверх ленты (одно окно с мини-плеером), тогда:
  - открытие плеера — разворачивается из нажатого видео / мини-плеера вверх, без системного перехода между экранами
  - свайп вниз и жест «назад» одинаково плавно сворачивают плеер в мини-плеер, под ним видна лента
  - тап по мини-плееру разворачивает обратно
- [ ] Панели описания/комментариев: плавный выезд снизу и закрытие с правильной высотой с первого раза, затемнение/скругление, свайп вниз по всей панели, а не только по шапке
- [ ] Масштаб «без полей» в полноэкранном режиме, как в YouTube: щипок двумя пальцами наружу — заполнить экран (RESIZE_MODE_ZOOM, края обрезаются), внутрь — вписать целиком (FIT); подсказка «Заполнить экран / Исходный размер»
- [ ] БАГ: в альбомной ориентации видео смещено от центра. Вероятная причина: окно плеера не заходит в область выреза камеры (отступ только с одной стороны). Исправление: layoutInDisplayCutoutMode = SHORT_EDGES / ALWAYS в полноэкранном режиме + рисовать под скрытыми системными панелями
- [ ] Настройки SponsorBlock: вместо переключателя вкл/выкл — пункт меню, открывающий экран: общий переключатель + выбор категорий (спонсор, самореклама, «подпишитесь/лайк», заставка, концовка, превью/повтор, не-музыка в клипах, отступления); для каждой категории — пропускать или нет
- [ ] Лимит дискового кэша превью и аватаров — 100 МБ (сейчас по умолчанию Coil до 250 МБ)
- [ ] Английский язык интерфейса: все строки в ресурсы (values-ru / values-en), язык по системе + выбор в меню аккаунта; язык запросов к YouTube (hl/gl) — по выбранному языку; после этого убрать «только на русском» из README
- [ ] Нормальные номера версий (0.1.x) в релизах и в приложении; внутренний номер сборки остаётся для Android
- [ ] Скриншоты в README

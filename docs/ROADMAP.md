# План развития

## Исправления к 0.2.0
- [ ] БАГ: видео 18+ не уходят в веб-плеер. Причина: обходной вариант из 0.1.8 (ссылка без расшифровки n) делает путь через аккаунт «успешным», затем воспроизведение падает с 403. Исправление: убрать этот вариант (ошибка n → AgeGateException → веб-плеер) + при 403 во время воспроизведения видео 18+ переключаться на веб-плеер

## Звук
- [ ] Выравнивание громкости между видео (как «стабильная громкость» YouTube): брать loudnessDb видео из ответа /player (playerConfig.audioConfig) и приглушать громкие ролики через громкость плеера (только ослабление — совместимо с audio offload). По умолчанию включено
- [ ] Буст громкости: LoudnessEnhancer на аудиосессии плеера, +3 / +6 / +10 дБ. По умолчанию выключен; при включении отключается audio offload — пометка «немного увеличивает расход батареи»
- [ ] «Ночной режим»: компрессор (DynamicsProcessing, Android 9+) — выравнивает громкость внутри видео (тихая речь / громкие сцены). По умолчанию выключен, тоже без offload
- [ ] Пункт «Звук» в меню: выравнивание, буст, ночной режим

# План развития

## 0.3.0 — музыка, звук, очередь

### Общая очередь (видео и музыка)
- [ ] Очередь воспроизведения: «Добавить в очередь» и «Играть следующим» в меню долгого тапа; просмотр и правка очереди
- [ ] Автовоспроизведение: после видео — следующее из очереди, иначе первое из рекомендаций (переключатель в плеере; для музыки — «радио» по похожим)

### YouTube Music
- [ ] Вкладка «Музыка» в нижней навигации: главная YouTube Music (подборки, миксы, «Быстрый выбор»), поиск по музыке (треки, альбомы, исполнители, плейлисты), библиотека (понравившиеся, плейлисты, альбомы) — через клиент WEB_REMIX (music.youtube.com) от имени аккаунта
- [ ] Музыкальный плеер: квадратная обложка, трек и исполнитель, перемотка, пред./след., повтор и перемешивание, очередь; видео не загружается вообще (только звук, audio offload)
- [ ] Очередь и «радио»: после трека — продолжение по похожим (как микс в YouTube Music), просмотр и правка очереди
- [ ] Страницы исполнителя и альбома
- [ ] Мини-плеер для музыки — тот же, что для видео, с обложкой
- [ ] Текст песни (если YouTube Music его отдаёт)

### Звук
- [ ] Выравнивание громкости между видео (как «стабильная громкость» YouTube): брать loudnessDb видео из ответа /player (playerConfig.audioConfig) и приглушать громкие ролики через громкость плеера (только ослабление — совместимо с audio offload). По умолчанию включено
- [ ] Буст громкости: LoudnessEnhancer на аудиосессии плеера, +3 / +6 / +10 дБ. По умолчанию выключен; при включении отключается audio offload — пометка «немного увеличивает расход батареи»
- [ ] «Ночной режим»: компрессор (DynamicsProcessing, Android 9+) — выравнивает громкость внутри видео (тихая речь / громкие сцены). Переключатель с галочкой прямо в меню шестерёнки плеера (быстро включить во время просмотра); по умолчанию выключен, без offload
- [ ] Пункт «Звук» в меню аккаунта: выравнивание и буст

### Плеер
- [ ] Картинка в картинке (PiP): при выходе на рабочий стол с развёрнутым плеером видео продолжает играть в маленьком окне. Пункт с галочкой «Картинка в картинке» в меню аватара; при включении — предупреждение «видео продолжит загружаться в окне, расход батареи выше». Без PiP в фоне по-прежнему только звук
- [ ] Таймер сна: 15 / 30 / 45 / 60 мин или «до конца видео», затем плавное затухание и пауза
- [ ] Запоминать скорость воспроизведения между видео (для музыки — всегда обычная)

### Библиотека аккаунта
- [ ] «Смотреть позже» и плейлисты аккаунта: раздел в меню аккаунта (или вкладка), открыть/воспроизвести плейлист целиком, «Сохранить в плейлист» / «Смотреть позже» в меню долгого тапа

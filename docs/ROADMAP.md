- [x] Автовоспроизведение: после видео — следующее из очереди, иначе первое из рекомендаций (переключатель в плеере; для музыки — «радио» по похожим)

### YouTube Music
- [x] Вкладка «Музыка» в нижней навигации: главная YouTube Music (подборки, миксы, «Быстрый выбор»), поиск по музыке (треки, альбомы, исполнители, плейлисты), библиотека (понравившиеся, плейлисты, альбомы) — через клиент WEB_REMIX (music.youtube.com) от имени аккаунта
- [x] Музыкальный плеер: квадратная обложка, трек и исполнитель, перемотка, пред./след., повтор и перемешивание, очередь; видео не загружается вообще (только звук, audio offload)
- [x] Очередь и «радио»: после трека — продолжение по похожим (как микс в YouTube Music), просмотр и правка очереди
- [x] Свои плейлисты YouTube Music: открыть и слушать целиком — по порядку или вперемешку, с повтором; после конца плейлиста — тишина или «радио» (по переключателю автовоспроизведения)
- [x] Страницы исполнителя и альбома
- [x] Мини-плеер для музыки — тот же, что для видео, с обложкой
- [x] Текст песни (если YouTube Music его отдаёт)

### Звук
- [x] Выравнивание громкости между видео (как «стабильная громкость» YouTube): брать loudnessDb видео из ответа /player (playerConfig.audioConfig) и приглушать громкие ролики через громкость плеера (только ослабление — совместимо с audio offload). По умолчанию включено
- [x] Буст громкости: LoudnessEnhancer на аудиосессии плеера, +3 / +6 / +10 дБ. По умолчанию выключен; при включении отключается audio offload — пометка «немного увеличивает расход батареи»
- [x] «Ночной режим»: компрессор (DynamicsProcessing, Android 9+) — выравнивает громкость внутри видео (тихая речь / громкие сцены). Переключатель с галочкой прямо в меню шестерёнки плеера (быстро включить во время просмотра); по умолчанию выключен, без offload
- [x] Пункт «Звук» в меню аккаунта: выравнивание и буст

### Плеер
- [x] Картинка в картинке (PiP): при выходе на рабочий стол с развёрнутым плеером видео продолжает играть в маленьком окне. Пункт с галочкой «Картинка в картинке» в меню аватара; при включении — предупреждение «видео продолжит загружаться в окне, расход батареи выше». Без PiP в фоне по-прежнему только звук
- [x] Таймер сна: 15 / 30 / 45 / 60 мин или «до конца видео», затем плавное затухание и пауза
- [x] Запоминать скорость воспроизведения между видео (для музыки — всегда обычная)

### Библиотека аккаунта

### Баги бет 0.3.0
Копятся здесь и правятся пачкой в следующей бете.
- [x] Библиотека: «Смотреть позже» и «Понравившиеся» — огромные пустые карточки (исправлено в beta.4)
- [x] Музыкальный плеер: кнопка «Следующий» не работает («Предыдущий» работает). Из шторки «следующий» работает — значит, дело в самой кнопке экрана
- [x] Музыкальный плеер: область нажатия «Плей/пауза» слишком большая — почти перекрывает «Предыдущий» (кнопки увеличены через scale, а он растягивает и зону нажатия; сделать крупные иконки размером, а не масштабом)
- [x] Переключение на следующий трек долгое (если трек ещё не открывался): заранее получать ссылки на следующий в очереди, пока играет текущий (и для видео тоже)
- [x] Вкладка «Музыка»: горизонтальные списки листаются неудобно — вместо них иногда перелистываются вкладки (ViewPager2 перехватывает свайп; пока палец на карусели, не отдавать жест вкладкам)
- [x] Музыка: обложки грузятся очень долго — сейчас берутся крупные (~544 px) для маленьких карточек; запрашивать по размеру карточки (параметр =wN-hN в ссылке), крупную — только в плеере; подгружать карусели заранее
- [x] Музыка: страница исполнителя (из поиска) грузится очень долго. Проверить: обложки (см. выше), разовое получение версии клиента YouTube Music (скачивает страницу music.youtube.com — делать заранее при запуске, как для видео), показывать содержимое по частям
- [x] Музыка: лайк трека не добавляет его в «Понравившуюся музыку» (появляется только исполнитель в библиотеке). Ставить лайк через клиент YouTube Music (WEB_REMIX like/like), проверить список «Понравившаяся музыка» и его догрузку
- [x] Исполнитель: «Воспроизвести всё» берёт только 5 треков из «Популярного». Нужны все треки: брать плейлист из ссылки «Все» у полки треков (browseEndpoint заголовка полки) и догружать его целиком
- [x] Музыка → Библиотека: «Понравившаяся музыка» задвоена (своя строка сверху без картинки + карточка в «Плейлистах»). Убрать свою строку — YouTube Music сам отдаёт этот плейлист с обложкой
- [x] Альбом и плейлист в музыке: кнопка «Сохранить в библиотеку» (лайк целиком) в шапке страницы — like/like с playlistId (у альбома — его audioPlaylistId), повторное нажатие убирает
- [x] Быстрый лайк трека прямо в строке списка (как «+» в Spotify): кнопка справа в каждой строке трека — в альбомах, плейлистах, поиске, у исполнителя; закрашена, если трек уже в «Понравившейся музыке». Также пункт «Нравится» в меню долгого тапа
- [x] Текст песни караоке, как в Spotify: построчно с подсветкой текущей строки и автопрокруткой, тап по строке — перемотка. Источник синхронизированного текста — YouTube Music (у части треков) или LRCLIB (бесплатная база с таймкодами, поиск по названию, исполнителю и длительности); если таймкодов нет — обычный текст. Показывать на экране плеера вместо обложки по кнопке «Текст»
- [x] Уведомление об ответе на комментарий: по нажатию ничего не происходит. Нужно открывать видео сразу с панелью комментариев на этой ветке (комментарий и ответы), чтобы прочитать и ответить. Ссылка в уведомлении — не обычный watchEndpoint: разобрать её (id видео и комментария, параметр lc), в журнал ошибок писать нераспознанный формат
- [x] Альбом: «В библиотеку» сохраняет, но вкладка «Библиотека» в музыке показывает старый список до перезапуска. Сбрасывать её кэш после сохранения/удаления альбома, плейлиста и лайка; плюс обновление свайпом вниз
- [x] Музыка → Библиотека → Исполнители: фото мелкие и размытые на больших карточках. У фото исполнителей ссылки вида «=s120-…» (а не «=wN-hN»), размер в них не подменяется — поддержать и этот формат
- [x] Музыка → Библиотека: вместо цветных обложек YouTube у встроенных плейлистов («Понравившаяся музыка» VLLM, «Сохранённые выпуски» VLSE) — свои монохромные: тёмная плитка с белой иконкой, в стиле приложения
- [x] Обновление без браузера: APK скачивается самим приложением (с прогрессом в окне/уведомлении), затем сразу открывается установщик пакетов. Разрешение REQUEST_INSTALL_PACKAGES + FileProvider; при первом обновлении Android один раз спросит «Разрешить установку из этого источника». То же для отката с беты
- [x] Переключение канала на «Стабильные» с беты: если уже вышла стабильная новее беты (например 0.3.0 при 0.3.0-beta.8) — предлагать обычное обновление до неё, а не откат к старой стабильной из файла отката
- [x] Бесконечная лента рекомендаций: сейчас догрузка останавливается, если очередная порция после фильтров (шортсы, трансляции, повторы) пустая или маленькая — прокрутка не срабатывает снова. Догружать следующую порцию автоматически, пока не наберётся новых видео; при ошибке — кнопка «Повторить» внизу вместо тихой остановки
- [x] Фото исполнителей в библиотеке музыки всё ещё мелкие (к релизу). Причина: исполнители приходят строками списка, где фото берётся на 120 px, а показываются большими карточками. В карточках запрашивать картинку под размер карточки (Music.sized), независимо от того, откуда пришёл элемент
- [x] Нельзя ответить на комментарий — только написать новый вне веток. Сейчас поле ответа появляется лишь внутри ветки, а ветку можно открыть только у комментариев, где уже есть ответы; к тому же у нового формата комментариев параметры ответа (replyParams) могут не находиться. Нужно: кнопка «Ответить» под каждым комментарием (открывает ветку с полем ввода, даже без ответов), надёжный разбор параметров ответа, а при их отсутствии — запись в журнал ошибок
- [x] ПАДЕНИЕ: «Service not registered» при отключении экрана от сервиса плеера (MediaController.release в Media3 1.6.1, после обрыва связи с сервисом). Обновить Media3 до свежей версии и не отпускать контроллер повторно / после разрыва
- [x] Журнал: ошибка 403 пишется до автоматического повтора со свежими ссылками — если повтор помог, запись лишняя. Писать только когда повтор не помог
- [x] Долгая пауза (ссылки YouTube живут ~6 ч): при возобновлении после многих часов заранее обновлять ссылки, а не ловить 403 и заметную паузу на перезагрузке
- [x] Журнал: «Unable to resolve host» (нет интернета) — не ошибка приложения. Не засорять журнал, а показывать «Нет подключения» на экране
- [x] Превью в ленте иногда не грузится (после долгого простоя или пропажи сети): ссылки превью бывают подписанными (?sqp=…&rs=…) и со временем истекают, а неудачная загрузка не повторяется. При ошибке — запасная ссылка без подписи (i.ytimg.com/vi/<id>/hqdefault.jpg) и повтор при появлении сети

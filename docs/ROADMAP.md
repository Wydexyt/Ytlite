# План развития

## 0.1.5 — быстрые правки
- [ ] Нормальные номера версий (0.1.x) в релизах и в приложении; внутренний номер сборки остаётся для Android
- [ ] Журнал ошибок: автоматически записывать падения и ошибки загрузки (время, версия, экран, текст и стек) в локальный файл с ограничением размера; в меню аккаунта — «Журнал ошибок» с кнопкой «Скопировать всё». Никуда не отправляется
- [ ] «Не интересует»: долгий тап по видео → меню с пунктом «Не интересует» (отметка в YouTube, видео скрывается из ленты)
- [ ] «Поделиться» в плеере и в меню долгого тапа: ссылка на видео, опционально с текущим временем (?t=…)
- [ ] Видео 18+ («age restricted»): запрашивать /player от имени активного аккаунта (cookie + SAPISIDHASH), расшифровку ссылок брать из NewPipe; без входа — сообщение «Видео 18+, войдите в аккаунт». Хрупко
- [ ] БАГ: в альбомной ориентации видео смещено от центра — рисовать в области выреза камеры (layoutInDisplayCutoutMode) и под скрытыми панелями
- [ ] Масштаб «без полей» в полноэкранном режиме: щипок наружу — заполнить экран (ZOOM), внутрь — вписать (FIT), с подсказкой
- [ ] Настройки SponsorBlock: пункт меню → экран с общим переключателем и выбором категорий (спонсор, самореклама, «подпишитесь/лайк», заставка, концовка, превью/повтор, не-музыка в клипах, отступления)
- [ ] Загружать все три ленты при запуске: сначала Главная, затем Подписки и История (только списки)
- [ ] Иконка приложения слева от «YT Lite» в шапке
- [ ] Лимит дискового кэша превью — 100 МБ

## 0.2.0 — большое обновление
- [ ] Плеер — выезжающая панель поверх ленты (одно окно с мини-плеером), анимации как в YouTube:

  - свайп вниз и «назад» одинаково плавно сворачивают в мини-плеер, под ним видна лента

- [ ] Мини-плеер на всех экранах: лента, поиск, страница канала (БАГ: сейчас не виден в поиске, на канале его нет)

- [ ] Загрузка как в YouTube: заставка с иконкой при запуске, серые карточки-заглушки с бликом вместо кружка
- [ ] Экран «Статистика» (неделя / месяц / всё время): время просмотра и график по дням, время в фоне / «Только звук», сэкономленный трафик (оценка), SponsorBlock (пропущено вставок и минут), число видео, топ-5 каналов. Счётчики только по событиям плеера, без таймеров

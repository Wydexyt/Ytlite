# YT Lite — что добавить

- [x] Кнопка смены ориентации в плеере (портрет ↔ альбом)
- [x] Иконка приложения
- [x] Свайп вниз для обновления ленты (pull-to-refresh)
- [x] Настройка качества воспроизведения
- [x] Двойной тап для перемотки на 5 с (левая/правая половина экрана); каждый следующий тап после двойного добавляет ещё 5 с, как в YouTube
- [x] Мини-плеер внизу ленты, пока видео играет в фоне: название, полоса прогресса, плей/пауза, крестик (остановить и закрыть); тап по мини-плееру открывает полный плеер
- [x] Ускорить старт воспроизведения. Идеи: прогрев NewPipeExtractor при запуске приложения (JS плеера, версия клиента), начинать получение потоков сразу по тапу, параллельно с открытием плеера, меньший стартовый буфер, сначала низкое качество с быстрым переключением на нужное
- [x] Не перезагружать ленту при переключении вкладок: держать загруженные списки и позицию прокрутки в памяти; обновлять только свайпом вниз (и, возможно, если данные старше N минут)
- [x] Лента как в YouTube: крупное превью на всю ширину, под ним аватар канала, название, канал · просмотры · дата, длительность поверх превью
- [x] Плеер в портретном режиме как в официальном приложении: видео сверху, под ним название, канал, описание (раскрывается) и рекомендации; в альбомном — на весь экран
- [x] Вместо кнопки «Выйти» — иконка (аватар) аккаунта; по нажатию всплывающее меню: «Добавить аккаунт», «Выйти». Нужна поддержка нескольких аккаунтов (хранить cookie каждого) и переключение между ними

## Следующая партия
- [x] Одна кнопка настроек в плеере вместо двух: убрать встроенную шестерёнку Media3, в своей — общее меню (качество, скорость, аудиодорожка)
- [x] Переключение вкладок ленты свайпом влево/вправо (с сохранением кэша и позиции каждой вкладки)
- [x] Белая полоса внизу (панель навигации) на Android 15+: в теме values-v35 не задан цвет панели навигации — задать тёмный / сделать прозрачной
- [x] Скрывать прямые трансляции («В ЭФИРЕ») из лент, поиска и рекомендаций
- [x] Открывать ссылки YouTube из других приложений: intent-filter на youtube.com/watch, m.youtube.com, youtu.be, /shorts/, /live/ + пункт в меню «Поделиться» (ACTION_SEND с текстом-ссылкой)
- [x] Таймкоды: в описании (и комментариях) кликабельные метки 1:23 / 1:02:03 → перемотка; учитывать параметр t= в открываемых ссылках
- [x] Описание и комментарии как в официальном приложении:
  - под видео: название, строка «просмотры · дата · ещё»; описание целиком не показывается
  - тап по названию/«ещё» → панель снизу, накрывающая область под видео (видео продолжает играть): полное описание, лайки/просмотры/дата, таймкоды; закрытие крестиком или свайпом вниз
  - карточка «Комментарии · N» с превью первого комментария; тап → такая же панель: список с догрузкой, переключатель «Популярные / Новые», у комментария — аватар, автор, время, текст, лайки, «N ответов» → вложенная страница ответов со стрелкой назад
  - написание комментариев (поле ввода внизу панели комментариев) и ответы на комментарии (поле во вкладке ответов), от имени активного аккаунта; без входа — поле скрыто
- [x] БАГ: развернуть кнопкой → назад жестом → бесконечный поворот. Причина: setFullscreenButtonState() в applyLayout вызывает слушатель кнопки, а тот делает toggle. Исправление: слушатель выставляет ориентацию по переданному isFullScreen (идемпотентно), а не переключает
- [x] Навигация как в официальном приложении: вкладки внизу экрана (иконка + маленькая подпись: Главная, Подписки, История), мини-плеер над ними; сверху тонкая шапка: название/логотип слева, справа лупа (поиск) и аватар аккаунта
- [x] Подсказки в поиске при вводе (как в YouTube, сервис suggestqueries) + локальная история запросов (показывать, пока поле пустое; удаление долгим нажатием); стрелка ↖ у подсказки подставляет её в поле

# YT Lite — что добавить

- [x] Кнопка смены ориентации в плеере (портрет ↔ альбом)
- [x] Иконка приложения
- [x] Свайп вниз для обновления ленты (pull-to-refresh)
- [x] Настройка качества воспроизведения
- [x] Двойной тап для перемотки на 5 с (левая/правая половина экрана); каждый следующий тап после двойного добавляет ещё 5 с, как в YouTube
- [x] Мини-плеер внизу ленты, пока видео играет в фоне: название, полоса прогресса, плей/пауза, крестик (остановить и закрыть); тап по мини-плееру открывает полный плеер
- [x] Ускорить старт воспроизведения. Идеи: прогрев NewPipeExtractor при запуске приложения (JS плеера, версия клиента), начинать получение потоков сразу по тапу, параллельно с открытием плеера, меньший стартовый буфер, сначала низкое качество с быстрым переключением на нужное
- [x] Не перезагружать ленту при переключении вкладок: держать загруженные списки и позицию прокрутки в памяти; обновлять только свайпом вниз (и, возможно, если данные старше N минут)
- [x] Лента как в YouTube: крупное превью на всю ширину, под ним аватар канала, название, канал · просмотры · дата, длительность поверх превью
- [x] Плеер в портретном режиме как в официальном приложении: видео сверху, под ним название, канал, описание (раскрывается) и рекомендации; в альбомном — на весь экран
- [x] Вместо кнопки «Выйти» — иконка (аватар) аккаунта; по нажатию всплывающее меню: «Добавить аккаунт», «Выйти». Нужна поддержка нескольких аккаунтов (хранить cookie каждого) и переключение между ними
